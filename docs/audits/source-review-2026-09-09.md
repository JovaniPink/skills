# Source review for the 0.12.0 candidate

All 20 changed sources have a review decision. One needs a focused link change: Swift moved its documentation. The other 19 still support the current instructions. Candidate acceptance also requires a passing final online check.

The starting inventory had 43 tracked URLs. Two reads of each found 20 changed fingerprints, including Drupal. The earlier count of 19 is historical. There were no HTTP retrieval failures or HTTP redirects, and no unstable preferred fingerprints. Swift used an HTML redirect; its destination was read in a browser. No normalization change was justified.

A fingerprint is a file or server marker used to flag a possible change. It cannot reconstruct the old page. Historical page bodies were unavailable for these comparisons. This review compares current official content with canonical instructions and earlier findings; it does not claim to know every upstream edit.

The [complete inventory and decisions](source-review-2026-09-09.json) retain old and current markers, affected skills, previous findings, and retrieval results. Raw responses remain in the private audit record. Only the 20 reviewed fingerprints were replaced. The other 23 markers and the catalog's existing review-age date remain unchanged. Their age was not reset by this check.

Three reviewed authorities were added: Swift's destination and the two W3C motion explanations. The final tracked inventory is 46 URLs. The Swift HTTP marker covers its application shell, so future semantic reviews must also inspect the rendered documentation. A stable fingerprint is not proof that all rendered content is unchanged.

Run `python3 scripts/check_upstream_freshness.py --online` after the reviewed pins are saved. Keep issue #25 open if it reports a retrieval failure, a changed marker, or an unresolved source. Do not refresh all pins to silence a failure.

The motion reference distinguishes [AAA interaction animation](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) from the applicable [Level A pause, stop, and hide requirements](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html).
