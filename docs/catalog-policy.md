# Catalog Placement Policy

A capability belongs in the public core when it is reusable across independent contexts, independently sourceable, safe to expose, and testable without private facts.

A capability belongs in a private overlay when correct execution depends on a private authority, identity, topology, contract, dataset, customer, product, or operational fact.

A capability belongs in neither when it is proprietary, unsafe, obsolete, duplicative, unsupported, or lacks demonstrated use.

Classification is evidence-based and reversible. A private capability can move to the public core only through clean-room authorship and a public boundary review. A public capability must move out of distribution if revocation evidence shows that it is unsafe or no longer supportable.
