# Catalog guidance

- Treat JSON schemas and their instances as public interfaces; update validation and tests together.
- Keep plugin packs as distribution units and profiles as skill-level activation units.
- Record workflow maturity, behavioral evidence, client compatibility, and runtime eligibility separately.
- Use surface-specific discovery measurements; never publish a universal client budget.
- Do not include private repository names, case identifiers, prompts, or product-specific findings in public records.
