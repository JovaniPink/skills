# Canonical skill guidance

- Edit only canonical `SKILL.md` files and focused references here; regenerate client projections afterward.
- Keep portable metadata string-valued and client invocation controls out of canonical frontmatter.
- Put the discriminating trigger first in each third-person description.
- Link required references directly from `SKILL.md`; avoid deeper reference chains.
- Do not add `allowed-tools`, hooks, agents, MCP servers, dependencies, or executable payloads without a separate reviewed release decision.
